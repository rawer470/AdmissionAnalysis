# AdmissionAnalysis

Веб-приложение для расчёта проходных баллов при поступлении в вуз. Загружаете конкурсные списки — получаете проходные баллы, списки зачисленных и PDF-отчёт.

Это командный кейс №3 для Московской предпрофессиональной олимпиады (профиль ИТ).

## Что делает

Приложение берёт CSV-файлы с данными абитуриентов (баллы, приоритеты, согласия) и распределяет их по четырём образовательным программам:

| Программа | Мест |
|-----------|------|
| Прикладная математика (ПМ) | 40 |
| Информатика и вычислительная техника (ИВТ) | 50 |
| Инфокоммуникационные технологии (ИТСС) | 30 |
| Информационная безопасность (ИБ) | 20 |

Распределение работает по алгоритму Deferred Acceptance: абитуриенты подаются на программы в порядке приоритетов, программы отбирают лучших по баллам, отклонённые пробуют следующий приоритет. Учитываются только те, кто дал согласие на зачисление.

## Технологии

Два сервиса: веб-интерфейс на ASP.NET Core (.NET 10) и Python API для расчётов (FastAPI). База данных — SQLite. PDF генерируется через ReportLab, графики — matplotlib.

## Установка

Нужны .NET 10+, Python 3.12+, Git.

```bash
git clone <repo>
cd AdmissionAnalysis

# Python
cd src/analysis
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# .NET
cd ../web
dotnet restore
```

## Тестовые данные

Генератор создаёт данные для 4 дней приёмной кампании с заданными проходными баллами:

```bash
cd src/analysis
python3 generate_mock_data.py
```

Результат:

| День | ПМ | ИВТ | ИТСС | ИБ |
|------|-----|-----|------|-----|
| 01 | недобор | недобор | недобор | недобор |
| 02 | 249 | 244 | 269 | 268 |
| 03 | 278 | 275 | 254 | 248 |
| 04 | 300 | 292 | 280 | 294 |

На третий день ПМ и ИВТ растут, ИТСС и ИБ падают. На четвёртый — все растут, итоговый рейтинг: ПМ > ИБ > ИВТ > ИТСС. Это соответствует требованиям ТЗ.

## Запуск

```bash
make dev  # оба сервиса сразу
```

Или по отдельности:
```bash
make api  # Python на :8000
make web  # ASP.NET на :5002
```

## Использование

**Загрузка данных:** http://localhost:5002/Admission/UploadCsv — выбираете день, загружаете 4 CSV файла. После загрузки автоматически запускается анализ и генерируется PDF.

**Статистика:** http://localhost:5002/Statistics — проходные баллы, график динамики, списки зачисленных, таблица статистики по приоритетам.

**Списки:** http://localhost:5002/Visualize — конкурсные списки с фильтрацией и сортировкой.

## API

```
GET /health                    — проверка
GET /api/analyze/{day}         — анализ за день
GET /api/generate_pdf_report   — PDF
GET /api/uploads               — список папок
GET /api/programs              — список программ
```

Swagger: http://localhost:8000/docs

## PDF-отчёт

Содержит всё по п.2.14 ТЗ: дату формирования, проходные баллы (или "недобор"), график динамики за 4 дня, списки зачисленных с ID и баллами, статистику заявлений и зачислений по приоритетам.
