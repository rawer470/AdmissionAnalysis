Командный кейс №3 для Московской предпрофессиональной олимпиады (профиль ИТ).

## Что умеет

Загружает CSV-файлы с данными абитуриентов. При повторной загрузке обновляет базу: добавляет новых, удаляет пропавших, обновляет изменившихся. Загрузка укладывается в 5 секунд (требование ТЗ).

Считает проходные баллы по алгоритму Deferred Acceptance, формирует списки зачисленных, показывает статистику по приоритетам. Умеет строить график динамики за несколько дней.

Генерирует PDF-отчёт и PNG-график. Результаты анализа сохраняет в JSON.

Веб-интерфейс: страница загрузки, страница статистики с графиками, конкурсные списки с фильтрами и сортировкой.

## Как работает распределение

Алгоритм Deferred Acceptance (отложенное принятие). Работает так:

1. Берём только тех, кто дал согласие на зачисление (`consent = true`)
2. Каждый абитуриент подаётся на программы по порядку приоритетов: сначала 1, потом 2, 3, 4
3. Программа принимает лучших по баллам в пределах квоты
4. Если приходит кто-то с баллом выше последнего зачисленного, он его вытесняет
5. Вытесненный пробует следующую программу по приоритету

При равных баллах побеждает абитуриент с меньшим ID.

Проходной балл: если зачислено меньше людей, чем мест, это НЕДОБОР (проходной не определён). Если квота заполнена, проходной равен баллу последнего зачисленного.

Пример:

```
Программа ПМ, 40 мест

Абитуриент #1: 300 баллов, приоритет 1 для ПМ → зачислен
Абитуриент #2: 250 баллов, приоритет 1 для ПМ → зачислен
...
Абитуриент #41: 295 баллов, приоритет 2 для ПМ → вытесняет #40 (у того 240)
Абитуриент #40: вытеснен → пробует свой приоритет 2
```

## Как пользоваться

**Загрузка данных** — http://localhost:5002/Admission/UploadCsv

Выбираете день (01, 02, 03 или 04), загружаете 4 CSV-файла (по одному на программу), жмёте «Загрузить». После этого данные попадают в базу, запускается анализ, генерируется PDF.

**Статистика** — http://localhost:5002/Statistics

Таблица проходных баллов, график динамики, списки зачисленных, статистика по приоритетам. Можно скачать PDF.

**Конкурсные списки** — http://localhost:5002/Visualize

Фильтры по программе, согласию, приоритету, баллам. Поиск по ID. Сортировка. Пагинация.

## Формат CSV

Имя файла: `{ПРОГРАММА}_{ДЕНЬ}_08.csv`. Например: `PM_01_08.csv`, `IVT_02_08.csv`.

Разделитель — точка с запятой, кодировка UTF-8.

```csv
id;consent;priority;physics_ict;russian;math;individual;total
178;0;1;100;100;100;9;309
85;1;1;95;98;99;10;302
42;1;2;88;92;95;8;283
```

Поля:

| Поле | Тип | Описание | Диапазон |
|------|-----|----------|----------|
| id | int | ID абитуриента | > 0 |
| consent | bool | Согласие | 0/1 |
| priority | int | Приоритет программы | 1-4 |
| physics_ict | int | Физика/ИКТ | 0-100 |
| russian | int | Русский | 0-100 |
| math | int | Математика | 0-100 |
| individual | int | Индивидуальные достижения | 0-10 |
| total | int | Сумма | 0-310 |

Согласие: `1`, `true`, `True`, `TRUE` — да. Всё остальное — нет.

## API

Базовый URL: `http://localhost:8000`

**GET /health** — проверка работоспособности. Возвращает `{"status": "healthy"}`.

**GET /api/analyze/{date_folder}** — анализ за день.

Путь: `date_folder` — папка с данными (`01`, `02`, `03`, `04`).

Опциональные параметры: `capacity_pm`, `capacity_ivt`, `capacity_itss`, `capacity_ib` (квоты, по умолчанию 40/50/30/20).

Пример:
```
GET /api/analyze/04?capacity_pm=45
```

Возвращает JSON с проходными баллами, списками зачисленных, статистикой по приоритетам.

**GET /api/generate_pdf_report** — генерация PDF.

Параметры: `date_folders` (дни через запятую), `target_date` (основной день).

```
GET /api/generate_pdf_report?date_folders=01,02,03,04&target_date=04
```

**GET /api/uploads** — список загруженных папок.

**GET /api/programs** — список программ с названиями.

Swagger UI: http://localhost:8000/docs

## Если что-то не работает

**`ModuleNotFoundError: No module named 'fastapi'`**

Забыли активировать venv или установить зависимости:
```bash
cd src/analysis
source .venv/bin/activate
pip install -r requirements.txt
```

**`Connection refused` при анализе**

Python API не запущен. Проверьте:
```bash
curl http://localhost:8000/health
```
Должно вернуть `{"status": "healthy"}`.

**Проходные баллы не те**

Скорее всего, данные грузятся из `uploads/` вместо `mock/`, или мало абитуриентов с согласием.
```bash
rm -rf data/uploads/*
cd src/analysis
python3 generate_mock_data.py
```

**Проблемы с кириллицей в PDF**

Нужен шрифт Arial Unicode или DejaVu Sans. Путь к шрифту задаётся в `report_manager.py`.

**`Folder not found: XX`**

Папка с данными не существует. Создайте или загрузите данные через веб.

**`stats.json` не найден при генерации PDF**

Сначала запустите анализ:
```bash
curl "http://localhost:8000/api/analyze/04"
```
