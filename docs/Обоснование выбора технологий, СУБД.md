## Обоснование выбора технологий

Язык и фреймворк веб-приложения
- **C# + ASP.NET Core MVC**: быстрая разработка форм и API, встроенная DI/Model Binding/Validation, хорошая поддержка EF Core для работы с БД.

Аналитический модуль
- **Python + FastAPI**: подходит для обработки данных, построения статистики, графики динамики конкурсных списков и генерации PDF-отчетов. FastAPI обеспечивает HTTP-взаимодействие между веб-приложением на .NET и аналитическим модулем.

Формат данных
- **CSV** для импорта: соответствует входным данным ТЗ, легко парсится.

## Обоснование выбора СУБД
СУБД
- **SQLite (через EF Core)**: требования ТЗ не фиксируют тип БД; SQLite лёгкая, встраиваемая, не требует отдельного сервера, достаточно быстра для объёмов кейса (до ≈5000 записей на день × 4 дня ≈ 20000). Позволяет атомарные транзакции (delete/insert/update) и переносима между окружениями. При росте нагрузки можно безболезненно перейти на PostgreSQL, оставив EF Core. За счёт локального хранения данных и транзакционного обновления обеспечивается возможность соблюдения ограничений ТЗ по времени загрузки конкурсных списков (≤ 5 с) и перестроения визуализаций (≤ 3 с).
