================================================================================
                   ДОКУМЕНТАЦИЯ КЛАССА AdmissionManager
================================================================================

Класс для управления процессом зачисления абитуриентов с учётом приоритетов,
расчёта конкурсной ситуации, определения проходных баллов и формирования
списков зачисленных.

================================================================================
КОНСТАНТЫ КЛАССА
================================================================================

PROGRAM_NAMES
    Словарь с полными названиями образовательных программ.
    
    Структура:
        {
            'pm': 'Прикладная математика',
            'ivt': 'Информатика и вычислительная техника',
            'itss': 'Инфокоммуникационные технологии и системы связи',
            'ib': 'Информационная безопасность'
        }

================================================================================
МЕТОДЫ КЛАССА
================================================================================

1. __init__(applicants_data, program_capacity)
   ----------------------------------------------------------------------------
   Конструктор класса. Инициализирует менеджер зачисления.
   
   ПАРАМЕТРЫ:
       applicants_data : dict
           Словарь с данными абитуриентов по программам.
           Формат: {program_code: [list of applicant dicts]}
           
           Где каждый applicant dict содержит:
               - id: int — уникальный идентификатор абитуриента
               - consent: bool — согласие на зачисление
               - priority: int — приоритет программы (1-4)
               - total: int — сумма баллов
               - math: int — балл по математике
               - russian: int — балл по русскому языку
               - physicsIct: int — балл по физике/ИКТ
               - individual: int — балл за индивидуальные достижения
       
       program_capacity : dict
           Словарь с количеством мест на каждой программе.
           Формат: {program_code: число мест}
   
   ВОЗВРАЩАЕТ:
       Экземпляр класса AdmissionManager
   
   ПРИМЕР:
       data = {
           'pm': [{...}, {...}],
           'ivt': [{...}, {...}]
       }
       capacity = {'pm': 40, 'ivt': 50, 'itss': 30, 'ib': 20}
       manager = AdmissionManager(data, capacity)


2. _run_admission()
   ----------------------------------------------------------------------------
   Внутренний метод. Запускает алгоритм распределения абитуриентов по
   программам с учётом приоритетов (алгоритм Deferred Acceptance).
   
   ОПИСАНИЕ РАБОТЫ:
       1. Объединяет данные из всех программ в единый словарь абитуриентов.
       2. Фильтрует только абитуриентов с согласием (consent=true).
       3. Каждый абитуриент подаётся на программу с приоритетом 1.
       4. Программы оставляют топ по баллам в пределах мест.
       5. Отклонённые подают на следующий приоритет (2, 3, 4).
       6. Процесс повторяется до стабилизации.
   
   ПРАВИЛА СОРТИРОВКИ:
       1. Сумма баллов (total) — по убыванию
       2. ID абитуриента — по возрастанию (тай-брейк при равенстве суммы)
   
   РЕЗУЛЬТАТ:
       Заполняет внутренние переменные:
           - self._enrolled — списки зачисленных по программам
           - self._enrolled_program — программа, куда зачислен абитуриент
           - self._all_applicants — все абитуриенты с приоритетами
   
   ПРИМЕЧАНИЕ:
       Метод вызывается автоматически при первом обращении к публичным
       методам. Результаты кэшируются.


3. calculate_competition_stats()
   ----------------------------------------------------------------------------
   Рассчитывает конкурсную ситуацию по каждой образовательной программе.
   
   ВОЗВРАЩАЕТ:
       dict — Словарь с конкурсной статистикой по каждой программе
       
       Формат:
           {
               'pm': {
                   'program_name': 'Прикладная математика',
                   'capacity': 40,
                   'enrolled_count': 38,
                   'applicants_with_consent': 95,
                   'competition_ratio': 2.38,
                   'status': 'НАБОР ЗАВЕРШЁН' или 'НЕДОБОР'
               },
               'ivt': {...},
               ...
           }
   
   ОПИСАНИЕ ПОЛЕЙ:
       program_name : str
           Полное название программы
       capacity : int
           Количество мест на программе
       enrolled_count : int
           Фактическое количество зачисленных
       applicants_with_consent : int
           Количество абитуриентов с согласием, указавших эту программу
       competition_ratio : float
           Конкурс (количество заявок на 1 место)
       status : str
           'НЕДОБОР' — если зачислено меньше мест
           'НАБОР ЗАВЕРШЁН' — если все места заняты
   
   ПРИМЕР:
       manager = AdmissionManager(data, capacity)
       stats = manager.calculate_competition_stats()
       print(stats['pm']['competition_ratio'])  # → 2.5


4. calculate_passing_score()
   ----------------------------------------------------------------------------
   Определяет проходной балл для каждой образовательной программы.
   
   ВОЗВРАЩАЕТ:
       dict — Словарь с проходными баллами
       
       Формат:
           {
               'pm': 285,      # проходной балл
               'ivt': 270,
               'itss': None,   # недобор
               'ib': 295
           }
   
   ЛОГИКА РАСЧЁТА:
       - Если зачислено меньше мест → None (недобор)
       - Если зачислено = количество мест → балл последнего зачисленного
   
   ПРИМЕЧАНИЕ:
       Проходной балл = сумма баллов последнего абитуриента в списке
       зачисленных (отсортированных по убыванию баллов).
   
   ПРИМЕР:
       scores = manager.calculate_passing_score()
       if scores['pm'] is None:
           print("На ПМ недобор")
       else:
           print(f"Проходной балл на ПМ: {scores['pm']}")


5. generate_enrollment_lists()
   ----------------------------------------------------------------------------
   Формирует списки зачисленных абитуриентов для каждой программы.
   
   ВОЗВРАЩАЕТ:
       dict — Словарь со списками зачисленных
       
       Формат:
           {
               'pm': [
                   {
                       'id': 101,
                       'total': 285,
                       'math': 95,
                       'russian': 90,
                       'physicsIct': 85,
                       'individual': 15,
                       'priority': 1
                   },
                   {...},
                   ...
               ],
               'ivt': [...],
               ...
           }
   
   ОПИСАНИЕ ПОЛЕЙ:
       id : int
           Уникальный идентификатор абитуриента
       total : int
           Сумма баллов
       math, russian, physicsIct, individual : int
           Баллы по отдельным предметам и достижениям
       priority : int
           Приоритет, с которым абитуриент зачислен на эту программу
   
   ПРИМЕЧАНИЕ:
       Списки отсортированы по убыванию суммы баллов.
   
   ПРИМЕР:
       enrolled = manager.generate_enrollment_lists()
       for applicant in enrolled['pm']:
           print(f"ID: {applicant['id']}, Балл: {applicant['total']}")


6. _generate_summary()
   ----------------------------------------------------------------------------
   Формирует полную сводку по всем требованиям технического задания.
   
   ВОЗВРАЩАЕТ:
       dict — Словарь с полной статистикой
       
       Формат:
           {
               'programs': {
                   'pm': {
                       'program_name': 'Прикладная математика',
                       'passing_score': 285 или 'НЕДОБОР',
                       'capacity': 40,
                       'total_applications': 95,
                       'applications_priority_1': 45,
                       'applications_priority_2': 30,
                       'applications_priority_3': 15,
                       'applications_priority_4': 5,
                       'enrolled_priority_1': 35,
                       'enrolled_priority_2': 3,
                       'enrolled_priority_3': 2,
                       'enrolled_priority_4': 0,
                       'total_enrolled': 40,
                       'enrolled_list': [{...}, {...}, ...]
                   },
                   'ivt': {...},
                   ...
               },
               'overall': {
                   'total_capacity': 140,
                   'total_enrolled': 135,
                   'total_applicants_with_consent': 450,
                   'programs_with_shortage': ['itss']
               }
           }
   
   ОПИСАНИЕ РАЗДЕЛОВ:
   
       programs : dict
           Детальная статистика по каждой программе:
           
           - program_name : str
               Полное название программы
           
           - passing_score : int или 'НЕДОБОР'
               Проходной балл
           
           - capacity : int
               Количество мест
           
           - total_applications : int
               Общее количество заявлений (с согласием)
           
           - applications_priority_X : int
               Количество заявлений с приоритетом X (1, 2, 3, 4)
           
           - enrolled_priority_X : int
               Количество зачисленных с приоритетом X
           
           - total_enrolled : int
               Всего зачислено
           
           - enrolled_list : list
               Полный список зачисленных с ID и баллами
       
       overall : dict
           Общая статистика:
           
           - total_capacity : int
               Всего мест на всех программах
           
           - total_enrolled : int
               Всего зачислено
           
           - total_applicants_with_consent : int
               Всего уникальных абитуриентов с согласием
           
           - programs_with_shortage : list
               Список программ с недобором
   
   ПРИМЕЧАНИЕ:
       Этот метод объединяет данные из других методов класса для
       формирования полного отчёта согласно ТЗ.
   
   ПРИМЕР:
       summary = manager._generate_summary()
       pm_stats = summary['programs']['pm']
       print(f"Проходной балл: {pm_stats['passing_score']}")
       print(f"Зачислено по 1 приоритету: {pm_stats['enrolled_priority_1']}")


7. get_statistics_report()
   ----------------------------------------------------------------------------
   Возвращает полный статистический отчёт о зачислении.
   
   ВОЗВРАЩАЕТ:
       dict — Полный отчёт
       
       Формат:
           {
               'competition': {...},      # см. calculate_competition_stats()
               'passing_score': {...},    # см. calculate_passing_score()
               'enrolled': {...},         # см. generate_enrollment_lists()
               'summary': {...}           # см. _generate_summary()
           }
   
   ОПИСАНИЕ РАЗДЕЛОВ:
       competition : dict
           Конкурсная статистика (результат calculate_competition_stats)
       
       passing_score : dict
           Проходные баллы (результат calculate_passing_score)
       
       enrolled : dict
           Списки зачисленных (результат generate_enrollment_lists)
       
       summary : dict
           Полная сводка (результат _generate_summary)
   
   НАЗНАЧЕНИЕ:
       Единая точка доступа ко всей информации о зачислении.
       Используется для формирования итоговых отчётов.
   
   ПРИМЕР:
       report = manager.get_statistics_report()
       
       # Проходные баллы
       print(report['passing_score']['pm'])
       
       # Конкурсная статистика
       print(report['competition']['pm']['status'])
       
       # Списки зачисленных
       for a in report['enrolled']['pm']:
           print(f"ID: {a['id']}, Балл: {a['total']}")
       
       # Детальная статистика
       pm_summary = report['summary']['programs']['pm']
       print(f"Зачислено по 1 пр: {pm_summary['enrolled_priority_1']}")


8. calculate_dynamics(data_by_days, capacity)  [СТАТИЧЕСКИЙ МЕТОД]
   ----------------------------------------------------------------------------
   Рассчитывает динамику проходных баллов по дням приёмной кампании.
   
   ПАРАМЕТРЫ:
       data_by_days : dict
           Словарь с данными по дням.
           Формат: {date: {program_code: [applicants]}}
           
           Пример:
               {
                   '01.08': {'pm': [...], 'ivt': [...], ...},
                   '02.08': {'pm': [...], 'ivt': [...], ...},
                   '03.08': {'pm': [...], 'ivt': [...], ...},
                   '04.08': {'pm': [...], 'ivt': [...], ...}
               }
       
       capacity : dict
           Словарь с количеством мест (одинаковый для всех дней).
           Формат: {program_code: число мест}
   
   ВОЗВРАЩАЕТ:
       dict — Динамика проходных баллов
       
       Формат:
           {
               'pm': {
                   'program_name': 'Прикладная математика',
                   'by_date': {
                       '01.08': 'НЕДОБОР',
                       '02.08': 275,
                       '03.08': 280,
                       '04.08': 285
                   }
               },
               'ivt': {...},
               ...
           }
   
   ОПИСАНИЕ:
       Для каждого дня создаётся отдельный AdmissionManager,
       рассчитываются проходные баллы, результаты группируются
       по программам и датам.
   
   НАЗНАЧЕНИЕ:
       Анализ изменения проходных баллов во времени в течение
       приёмной кампании (4 дня: 01.08 - 04.08).
   
   ПРИМЕР:
       data_by_days = {
           '01.08': load_data('01.08'),
           '02.08': load_data('02.08'),
           '03.08': load_data('03.08'),
           '04.08': load_data('04.08')
       }
       capacity = {'pm': 40, 'ivt': 50, 'itss': 30, 'ib': 20}
       
       dynamics = AdmissionManager.calculate_dynamics(data_by_days, capacity)
       
       print("Динамика ПМ:")
       for date, score in dynamics['pm']['by_date'].items():
           print(f"  {date}: {score}")


================================================================================
АЛГОРИТМ РАСПРЕДЕЛЕНИЯ (DEFERRED ACCEPTANCE)
================================================================================

ОПИСАНИЕ:
    Класс использует алгоритм Deferred Acceptance для справедливого
    распределения абитуриентов по программам с учётом приоритетов.

ОСНОВНЫЕ ПРИНЦИПЫ:
    1. Каждый абитуриент зачисляется максимум на одну программу.
    
    2. Абитуриент сначала подаётся на программу с приоритетом 1.
       Если не проходит → пробует приоритет 2, затем 3, затем 4.
    
    3. На каждой программе места занимают абитуриенты с наибольшими
       баллами (независимо от приоритета программы для них).
    
    4. Если абитуриент закрепился на программе с высоким приоритетом,
       его баллы НЕ участвуют в конкурсе на программы с низким приоритетом.
    
    5. Учитываются только абитуриенты с согласием (consent=true).

ПРИМЕР РАБОТЫ:
    Пусть есть 2 программы: X (1 место), Y (1 место)
    Абитуриенты:
        - A: 100 баллов, X — приоритет 1, Y — приоритет 2
        - B: 90 баллов, X — приоритет 1, Y — приоритет 2
        - C: 85 баллов, Y — приоритет 1
    
    ШАГ 1: A и B подают на X (приоритет 1), C подаёт на Y (приоритет 1)
           X оставляет A (100 > 90), отклоняет B
           Y оставляет C
    
    ШАГ 2: B подаёт на Y (приоритет 2)
           Y сравнивает C (85) и B (90) → оставляет B, отклоняет C
    
    ШАГ 3: C больше нет приоритетов → не зачислен
    
    ИТОГ: X — A (100), Y — B (90), C — не зачислен

ПРИМЕР 1: Базовое использование
    
    from admission_stats import AdmissionManager
    
    # Загрузка данных
    data = load_applicants_data()  # ваша функция загрузки
    capacity = {'pm': 40, 'ivt': 50, 'itss': 30, 'ib': 20}
    
    # Создание менеджера
    manager = AdmissionManager(data, capacity)
    
    # Получение проходных баллов
    scores = manager.calculate_passing_score()
    print(f"Проходной балл на ПМ: {scores['pm']}")
    
    # Получение списков зачисленных
    enrolled = manager.generate_enrollment_lists()
    print(f"Зачислено на ПМ: {len(enrolled['pm'])} человек")


ПРИМЕР 2: Полный отчёт
    
    manager = AdmissionManager(data, capacity)
    report = manager.get_statistics_report()
    
    # Проходные баллы по всем программам
    for prog, score in report['passing_score'].items():
        name = AdmissionManager.PROGRAM_NAMES[prog]
        print(f"{name}: {score if score else 'НЕДОБОР'}")
    
    # Детальная статистика по ПМ
    pm_stats = report['summary']['programs']['pm']
    print(f"\nПрикладная математика:")
    print(f"  Заявок 1 приоритета: {pm_stats['applications_priority_1']}")
    print(f"  Зачислено 1 приоритета: {pm_stats['enrolled_priority_1']}")
    print(f"  Всего зачислено: {pm_stats['total_enrolled']}")


ПРИМЕР 3: Динамика по дням
    
    # Загрузка данных за 4 дня
    data_by_days = {}
    for date in ['01.08', '02.08', '03.08', '04.08']:
        data_by_days[date] = load_data_for_date(date)
    
    capacity = {'pm': 40, 'ivt': 50, 'itss': 30, 'ib': 20}
    
    # Расчёт динамики
    dynamics = AdmissionManager.calculate_dynamics(data_by_days, capacity)
    
    # Вывод динамики для ПМ
    print("Динамика проходного балла на ПМ:")
    for date in ['01.08', '02.08', '03.08', '04.08']:
        score = dynamics['pm']['by_date'][date]
        print(f"  {date}: {score}")


================================================================================
ТЕХНИЧЕСКИЕ ДЕТАЛИ
================================================================================

ПРОИЗВОДИТЕЛЬНОСТЬ:
    - Временная сложность алгоритма: O(n × p), где n — число абитуриентов,
      p — число приоритетов (максимум 4)
    - Результаты расчётов кэшируются для ускорения повторных обращений
    - Время загрузки и обработки не должно превышать 5 секунд (по ТЗ)

ОГРАНИЧЕНИЯ:
    - Максимум 4 приоритета на абитуриента
    - Приоритеты должны быть от 1 до 4
    - ID абитуриентов должны быть уникальными
    - Согласие (consent) — булево значение (true/false)

ОСОБЕННОСТИ РЕАЛИЗАЦИИ:
    - Используется алгоритм Deferred Acceptance (отложенного принятия)
    - Сортировка по баллам: сумма (убывание) → ID (возрастание)
    - Только абитуриенты с согласием (consent=true) участвуют в распределении
    - Каждый абитуриент может быть зачислен только на одну программу


================================================================================
КОДЫ ПРОГРАММ
================================================================================

pm   — Прикладная математика (40 мест)

itss — Инфокоммуникационные технологии и системы связи (30 мест)
ib   — Информационная безопасность (20 мест)
